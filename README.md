<h1 align="center">STORM TRANSLATOR</h1>

## **О проекте**
STORM TRANSLATOR — специализированный инструмент для перевода субтитров, скриптов видеоигр, строковых ресурсов и текстовых файлов локализации с поддержкой глоссариев терминов и пакетной обработки.

## **Происхождение и форки**
Оригинальная разработка в составе экосистемы STORM SOFT.

## **Технологический стек**
- **Языки программирования**: TypeScript, JavaScript, Python
- **Интерфейс**: React, Tailwind CSS, Electron
- **Форматы файлов**: SRT, ASS, JSON, PO/POT, CSV, XML, INI

## **Ключевые возможности**
- **Двухоконный редактор строк**: Синхронный просмотр оригинала и перевода с валидацией спецсимволов и тегов форматирования.
- **Подключение пользовательских глоссариев**: Автоматическая подстановка фиксированных терминов и имен собственных.
- **Пакетный перевод через AI**: Перевод сотен файлов одновременно с сохранением исходной структуры разметки.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64, ARM64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_TRANSLATOR_<версия>_Setup.exe` или архив `STORM_TRANSLATOR_<версия>.zip` из **Releases** на GitHub.
2. Установите и запустите приложение.
